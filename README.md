# Staniforth Road — A house, reimagined

A personal 6 minute 22 second film tracing the house renovation from September 2021 to October 2026, in seven chapters. This edition includes a seven-second gate opening followed by 56 full-frame media shots, 23 original video excerpts in total, cinematic character-by-character text reveals and seven animated geometric chapter portraits.

The opening uses exactly seconds 8–15 of `20220227_145740.mp4`. “A new chapter” now includes the user-selected `VID_20260301_134259.mp4`, `VID_20260322_173909.mp4` and `VID_20261018_181741.mp4`, showing the completed interiors and October vegetable garden.
